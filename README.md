# 🍷 Wine Quality Prediction

## 📌 Project Overview
This project focuses on predicting the **quality of wine** based on its chemical characteristics such as acidity, density, pH, and alcohol content. It demonstrates the application of machine learning in a real-world scenario within the wine industry.

Multiple classification models are used to compare performance and identify the most effective approach.

---

## 🎯 Objectives
- Analyze wine dataset  
- Perform data cleaning and preprocessing  
- Explore chemical properties affecting quality  
- Train multiple classification models  
- Compare model performance  
- Visualize results  

---

## 📂 Dataset
- Wine Quality Dataset  
- Includes features like:
  - Acidity  
  - Density  
  - pH  
  - Alcohol  
  - Sulphates  
  - Residual sugar
